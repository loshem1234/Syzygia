# Fonts

- **GFSDidot-Regular.ttf** — GFS Didot by the Greek Font Society. Polytonic Greek. SIL Open Font License 1.1.
- **EBGaramond-Regular.ttf / EBGaramond-Italic.ttf** — EB Garamond by Georg Duffner and Octavio Pardo. SIL Open Font License 1.1.

Built by merging the Latin, Latin Extended, Greek and Greek Extended subsets published by Fontsource into single files, so PDF exports carry every polytonic glyph. Used only for PDF export.
